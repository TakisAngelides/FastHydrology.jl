Shakti

Shakti is a transient model, it owns its grid and state and is solved at every time step. FastHydrology only wraps it in ShaktiHydroModel and TimeSimulation, all the physics lives in Shakti.jl, see there for the model, its options and real-data examples.

Both packages export run! and step!, so call them as FastHydrology.run!.

This page is a short version of the Shakti.jl tutorial: the SHMIP ice-sheet margin (de Fleurian et al. 2018), a flat bed under ice that is 1 m thick at the terminus and about 520 m thick 20 km inland, with 1 m/a of melt water from above. It runs when the docs are built: 40 x 10 cells and 30 one-day steps, a few seconds. The tutorial runs a year on an 80 x 20 grid.

using FastHydrology
using Shakti
using CairoMakie

Grid and mask

The slab is uniform in y. The terminus at x = 0 is land, an outlet at atmospheric pressure; the other sides are closed (OTHER_BASIN, and the grid edge). Every grounded region needs an outlet.

nx, ny = 40, 10
grid = Shakti.Grid(nx, ny, 20000.0, 5000.0)

mask = fill(Shakti.GROUNDED, nx, ny)
mask[1, :]      .= Shakti.LAND
mask[end, :]    .= Shakti.OTHER_BASIN
mask[:, [1, end]] .= Shakti.OTHER_BASIN

Geometry and inputs

Flat bed, SHMIP surface, a 1 cm initial gap, 1 m/a of melt, 1e-6 m/s of sliding.

Wrap and run

The default sheet (a head below the bed empties the cavity, water above the overburden lifts the ice) has a non-symmetric head matrix, so it needs an LU solver. Step through with FastHydrology.step! and keep the fields at a few days: N [Pa], the gap height b [m] and the Reynolds number Re.

nsteps, dt = 30, 86400.0
ls = Shakti.LUDirectSolver(grid)
ps = Shakti.PicardSolver(200, 1e-6, ls, grid)
shakti_sim = Shakti.Simulation(grid, state, nsteps, dt, p, String[], mi, sl; ps = ps)
time_sim   = TimeSimulation(ShaktiHydroModel(shakti_sim))

frames = [1, 3, 10, 30]
snap = Dict{Int, NamedTuple}()
for k in 1:nsteps
    FastHydrology.step!(time_sim)
    k in frames && (snap[k] = (N = Array(state.N), b = Array(state.b), Re = Array(state.Re)))
end

Plot

A profile along x through the middle row, grounded cells only. N goes to zero at the outlet, where the ice is thin and the water drains at atmospheric pressure. The gap opens near the terminus, where the flux is largest, and closes inland; it needs about 100 days to settle, so 30 days shows the start of it.

gr = Array(state.mask) .== Shakti.GROUNDED
jm = ny ÷ 2
ix = findall(gr[:, jm])
colors = cgrad(:viridis, length(frames); categorical = true)

fig = Figure(size = (720, 640))
rows = [("N [MPa]", s -> s.N[ix, jm] ./ 1e6, identity),
        ("b [mm]", s -> s.b[ix, jm] .* 1e3, identity),
        ("Re", s -> s.Re[ix, jm], log10)]
for (r, (name, f, scale)) in enumerate(rows)
    ax = Axis(fig[r, 1]; ylabel = name, yscale = scale,
              xlabel = r == 3 ? "x [km]" : "", xticklabelsvisible = r == 3)
    for (c, k) in enumerate(frames)
        lines!(ax, xkm[ix], f(snap[k]); color = colors[c], linewidth = 2, label = "day $k")
    end
    r == 2 && Legend(fig[1:3, 2], ax; framevisible = false)
end
